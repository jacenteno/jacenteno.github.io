Arquitectura Kiosko de Alta Seguridad

Análisis técnico de la implementación de bloqueo de sistema, gestión de publicidad y seguridad en dispositivos retail.

1. Implementación de Kiosk Mode (Lock Task)

Bloqueo de Sistema

Uso de startLockTask() y configuración de la app como Home Launcher en el AndroidManifest. Esto previene que el usuario salga de la aplicación mediante gestos o botones físicos.

<category android:name="android.intent.category.HOME" /> <category android:name="android.intent.category.DEFAULT" />

Immersive Sticky Mode

Ocultación sistemática de barras de estado y navegación con la clase WindowInsetsControllerCompat, asegurando que la interfaz ocupe el 100% de la pantalla sin distracciones.

2. Capa de Seguridad y Timeouts

Acceso Protegido por IT

Las funciones críticas (ajustes de red, URLs de API) están protegidas por un login administrativo. Se ha implementado un temporizador reactivo de 30 segundos.

LaunchedEffect(Unit) { while (secondsRemaining > 0) { delay(1000) secondsRemaining-- } navController.popBackStack() // Auto-exit }

3. Arquitectura de Datos Reactiva

Retrofit & MVVM

Comunicación asíncrona mediante corrutinas de Kotlin para la consulta de productos. Uso de StateFlow para propagar cambios de la API a la UI en tiempo real.

Media3 & ExoPlayer

Gestión eficiente de recursos multimedia para la publicidad. Cacheo inteligente de videos para funcionamiento estable incluso ante fluctuaciones de ancho de banda.
